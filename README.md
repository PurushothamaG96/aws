# AWS Learning Repository

Welcome to the **AWS Learning Repository**! This repository is a curated and well-structured collection of notes, examples, diagrams, and summaries created while learning and practicing AWS services. It serves as a personal knowledge hub as well as a helpful reference for anyone preparing for **AWS Cloud Practitioner**, **AWS Solutions Architect Associate**, or general AWS hands‑on learning.

---

## 📘 Overview

This repository contains organized documentation of core AWS concepts, services, real-world examples, and exam‑oriented notes. All content is written in a clean and easy-to-understand format with explanations, diagrams, use-cases, and important points.

## 🧩 Key AWS Topics Covered

### **1. Compute**

* EC2 instance types, purchase options, security groups
* Auto Scaling Groups & Load Balancers (ALB/NLB/CLB)
* Lambda, layers, concurrency, event triggers

### **2. Storage**

* S3 (bucket basics, versioning, lifecycle, encryption)
* EBS volume types & snapshots
* EFS for scalable file storage

### **3. Database**

* RDS engine comparisons
* Aurora cluster architecture
* DynamoDB partition keys, GSIs, LSIs, DAX

### **4. Networking**

* VPC components: Subnets, Route Tables, IGW, NAT
* VPC Peering, Transit Gateway
* CloudFront caching, Route53 routing policies

### **5. Security & Identity**

* IAM Users, Groups, Roles, Policies
* KMS encryption types
* Secrets Manager vs Systems Manager Parameter Store

### **6. DevOps & Infrastructure as Code**

* CI/CD using CodeCommit, CodeBuild, CodeDeploy, CodePipeline
* CloudFormation templates & best practices
* Monitoring with CloudWatch & CloudTrail

### **7. Serverless**

* API Gateway integrations
* EventBridge rules
* Step Functions workflows

### **8. Exam Preparation Notes**

* Service summaries
* Must-know scenario questions
* Visual learning diagrams
* FAQs asked repeatedly in exams
